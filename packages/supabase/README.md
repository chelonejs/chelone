# @chelone/supabase

The Supabase data and auth providers for Chelone, a headless admin engine.

```bash
pnpm add @chelone/supabase @supabase/supabase-js
```

The `chelone-supabase gen` bin writes Zod schemas and a typed resources file from `supabase gen types typescript` output.

Docs: https://chelone.dev
