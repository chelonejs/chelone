---
title: "Resource Registry & Codegen"
description: "The registry as a runtime value, and the codegen that writes its map and augmentation."
---

This page will cover the registry as a value a running app reads
(`useResourceRegistry`, `<ResourceRegistryProvider>`), and the Supabase codegen
command `chelone-supabase gen`, which writes the `defineResources` map, its
references and its `Register` augmentation from your database types.
