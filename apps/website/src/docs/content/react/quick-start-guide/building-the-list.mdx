description: "Render a DataTable of records with reference, number, and boolean fields."
---

The `list` view of a resource is where users browse records. Chelone's `<List>`
fetches the current page and publishes it to a `<DataTable>`; each `<DataTable.Col>`
picks a field to render.

## A live list

Here is the `posts` list, running against the in-memory provider — a real
`<DataTable>` over seeded records:

<ComponentPreview name="react/quick-start-guide/post-list" />

The code:

```tsx title="src/posts.tsx"
import {
  BooleanField,
  DataTable,
  EditButton,
  List,
  ReferenceField,
  TextField,
} from "@chelone/react";

export function PostList() {
  return (
    <List>
      <DataTable>
        <DataTable.Col source="title" />
        <DataTable.Col label="Author">
          <ReferenceField source="author_id" reference="authors">
            <TextField source="name" />
          </ReferenceField>
        </DataTable.Col>
        <DataTable.NumberCol source="views" />
        <DataTable.Col source="published">
          <BooleanField source="published" />
        </DataTable.Col>
        <DataTable.Col>
          <EditButton />
        </DataTable.Col>
      </DataTable>
    </List>
  );
}
```
