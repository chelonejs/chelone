Shows a record value and turns it into an input on click. It reads the record in context, sends only the changed fields through `update`, and makes no call when nothing changed. `Escape` cancels, and a blur cancels unless `cancelOnBlur` is false. Editing needs `edit` access to the resource. Do not put it inside an `<Edit>` or `<Create>` form: it has a form of its own.
