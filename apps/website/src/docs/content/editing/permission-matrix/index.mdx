A tab per role, each holding a resource by action grid of checkboxes over that role's grants. The value maps each role id to a `Permission[]` that `canAccessWithPermissions` reads. A cell granted by a wildcard shows as a locked checked cell. The matrix gates nothing itself: wrap it in `<CanAccess>` to decide who sees it. In Vue the value is a `v-model`.
