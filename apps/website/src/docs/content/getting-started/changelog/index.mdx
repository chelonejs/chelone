Chelone is pre-release. This page will track notable changes once the first
version ships.

## v1 (unreleased)

The initial release, currently in development:

- **`@chelone/core`** — the framework-agnostic headless engine: the data
  provider contract, the Zod-backed resource registry, the list / create / edit
  / show controllers, validation, i18n, and the store.
- **`@chelone/react`** — the React adapter: the controller hooks and the full
  shadcn-native admin surface (views, fields, inputs, buttons, layout, auth).
- **`@chelone/vue`** — the Vue 3 adapter on the same core, built on
  `vue-router` 4 and `@tanstack/vue-query`.
- **`@chelone` shadcn registry** — the React admin components distributed as
  source (`packages/react/registry.json`), installable with the shadcn CLI. The
  Vue components ship inside `@chelone/vue`.

Follow along on [GitHub](https://github.com/chelonejs/chelone) for progress
toward the v1 release.
