Edits a GeoJSON `GeometryCollection` with every draw tool, then `cut`, `edit`, `move` and `delete`. Every shape stays in the value. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { GeometryCollectionInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
