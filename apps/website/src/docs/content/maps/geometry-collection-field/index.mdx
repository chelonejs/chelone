Shows a GeoJSON `GeometryCollection` from a record on a map, drawing each geometry by its own type. A collection with no coordinates shows the empty text panel. It is `GeoJsonField` under the name of a GeoJSON type, so it takes the same props.

## Installation

```tsx
import { GeometryCollectionField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
