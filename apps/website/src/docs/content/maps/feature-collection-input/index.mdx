Edits a GeoJSON `FeatureCollection` with the tools of its `allowedShapes`, `Point`, `LineString` and `Polygon` by default. Each feature keeps its own `properties` when another is removed. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { FeatureCollectionInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
