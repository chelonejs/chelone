Edits a GeoJSON value in a form field by drawing on a map: `kind` says what the field holds and picks the `tools` the toolbar shows. Each finished drawing, vertex drag, move or removal is written to the field, and a part the editor cannot hold shows read-only and stays in the value. The named inputs (`PointInput`, `PolygonInput`, ...) are this component with `kind` and `tools` set for you.

## Installation

```tsx
import { ShapeInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
