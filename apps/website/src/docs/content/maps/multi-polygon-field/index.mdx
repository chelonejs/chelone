Shows a GeoJSON `MultiPolygon` from a record on a map, one filled part per polygon. It is `GeoJsonField` under the name of a GeoJSON type, so it takes the same props.

## Installation

```tsx
import { MultiPolygonField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
