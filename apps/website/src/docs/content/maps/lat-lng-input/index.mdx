Edits a latitude and a longitude held in two form fields, `latSource` and `lngSource`, by typing or by clicking a map. A click or a pin drag writes both fields rounded to 6 decimals and calls `onPositionChange`; typing never calls it.

## Installation

```tsx
import { LatLngInput } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
