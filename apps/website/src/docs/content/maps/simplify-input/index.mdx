Thins a stored GeoJSON value with a `tolerance` slider and previews the result on a map: the form holds the simplified value. Every change simplifies from the first value, so sliding back to `minTolerance` restores it. `quality` picks the algorithm, `High` keeping more detail. A null value shows an empty state, and any other value than GeoJSON or null throws.

## Installation

```tsx
import { SimplifyInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
