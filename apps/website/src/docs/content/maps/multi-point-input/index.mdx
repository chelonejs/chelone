Edits a GeoJSON `MultiPoint` by drawing on a map with `draw-point`, `edit`, `move` and `delete`. Each point is its own feature on the map. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { MultiPointInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
