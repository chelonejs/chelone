Shows a point held in two record fields, `latSource` and `lngSource`, as a marker on a map centred on it. A missing, null, non-numeric or out-of-range coordinate shows a text panel in its place; `0` is a position.

## Installation

```tsx
import { LatLngField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
