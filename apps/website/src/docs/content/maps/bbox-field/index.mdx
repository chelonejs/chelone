Shows a `BBox` value from a record, `[west, south, east, north]`, as a rectangle on a map. A value that is not four finite numbers shows the empty text panel. It is `GeoJsonField` over a box, so it takes the same props.

## Installation

```tsx
import { BBoxField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
