Edits a GeoJSON `MultiPolygon` with the tools of `PolygonInput`. Each part is its own feature on the map, and a part with a hole draws read-only and stays in the value. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { MultiPolygonInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
