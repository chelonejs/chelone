Edits a GeoJSON `Point` by drawing on a map with `draw-point`, `move` and `delete`. A new point replaces the old one. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { PointInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
