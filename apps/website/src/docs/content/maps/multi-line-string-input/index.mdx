Edits a GeoJSON `MultiLineString` by drawing on a map with `draw-line`, `edit`, `move` and `delete`. Each line is its own feature on the map. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { MultiLineStringInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
