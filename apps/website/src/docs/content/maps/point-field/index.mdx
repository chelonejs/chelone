Shows a GeoJSON `Point` from a record on a map as a circle marker, zoomed to `maxFitZoom`, 18 by default. It is `GeoJsonField` under the name of a GeoJSON type, so it takes the same props.

## Installation

```tsx
import { PointField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
