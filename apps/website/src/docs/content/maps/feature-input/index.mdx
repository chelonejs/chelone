Edits a GeoJSON `Feature` with the tools of its `shape`, `Polygon` by default. An edit keeps the feature's `id` and `properties`. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { FeatureInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
