Shows a GeoJSON `Polygon` from a record on a map, filled at `fillOpacity`, 0.2 by default, and outlined with `color` and `weight`. It is `GeoJsonField` under the name of a GeoJSON type, so it takes the same props.

## Installation

```tsx
import { PolygonField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
