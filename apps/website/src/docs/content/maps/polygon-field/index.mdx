Shows a GeoJSON `Polygon` from a record on a map, filled at 0.2 opacity and outlined 3 pixels wide, both through `shapeStyle`. It is `GeoJsonField` under the name of a GeoJSON type, so it takes the same props.

## Installation

```tsx
import { PolygonField } from "@chelone/react/maps";
```
