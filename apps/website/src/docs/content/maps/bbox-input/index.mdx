Edits a `BBox` value, `[west, south, east, north]`, by drawing a rectangle with `draw-rectangle`, `edit`, `move` and `delete`. A new rectangle replaces the old one, and `aspectRatio` grows the stored box around its centre to that width over height. It is `ShapeInput` with `kind` and `tools` set for you, so its table holds neither.

## Installation

```tsx
import { BBoxInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
