A button that removes OpenStreetMap areas, such as the water in a delivery area, from the Polygon or MultiPolygon held in `source`, queried from Overpass by `presets` and `tags`. The request runs on the click, and the result is written like a user edit, so the form turns dirty and the field's validators run. Areas that cover the value entirely clear the field to null, and a cut that would leave a Polygon as several pieces is refused with a warning and the value is left as it was. Needs an Overpass provider, from `provider` or `MapsProvider`. It is `OsmFeatureOperator` with `mode` set to `subtract` for you.

## Installation

```tsx
import { OsmFeatureSubtract } from "@chelone/react/maps/osm";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
