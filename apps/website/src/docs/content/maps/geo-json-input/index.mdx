Edits any one GeoJSON geometry, or with `collection` a `GeometryCollection`, limited to the `shapes` the user may draw, all three by default. Without `collection` a new drawing replaces the old one. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { GeoJsonInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
