Edits a GeoJSON `Polygon` by drawing on a map with `draw-polygon`, `draw-rectangle`, `draw-circle`, `cut`, `edit`, `move` and `delete`. A new drawing replaces the old one. It is `ShapeInput` under the name of a GeoJSON type, with `kind` set for you.

## Installation

```tsx
import { PolygonInput } from "@chelone/react/maps/draw";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
