Shows a GeoJSON `Geometry`, `Feature` or `FeatureCollection` from a record on a map, framed to fit it. A null, a string, a number or a malformed object shows a text panel in its place: a string that holds JSON text is never parsed. The named fields (`PointField`, `PolygonField`, ...) are this component.

## Installation

```tsx
import { GeoJsonField } from "@chelone/react/maps";
```

See the [maps guide](/docs/app-config/maps) for the subpaths, the optional packages and `MapsProvider`.
