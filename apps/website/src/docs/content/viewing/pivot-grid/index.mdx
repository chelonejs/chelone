The records of the ambient `<List>` as a table of rows by columns, with row, column and grand totals. The grid fetches nothing, so give the list a `perPage` that covers every record to pivot. `count`, the default, counts records; `sum`, `avg`, `min` and `max` read `valueSource` and skip values that are not numbers. A total aggregates the raw values, not the cells. A record with no row or column value lands in a `(none)` row or column.
