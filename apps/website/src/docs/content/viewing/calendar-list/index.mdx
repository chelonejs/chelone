The records of the ambient `<List>` as events in a month, week or agenda view. The list is filtered to the visible range with `<startSource>_gte` and `<startSource>_lte`, which `rangeFilter` renames, and `perPage` is 1000. Dates read as local time, and a date-only value is local midnight. `onDrop` is for the month view, uses native drag and drop, and does not work on touch screens.
