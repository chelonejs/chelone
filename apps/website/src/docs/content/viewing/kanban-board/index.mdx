The records of the ambient `<List>` as columns, one per column definition, with a card per record. The board fetches nothing, so give the list a perPage that covers every card; a record whose group value names no column is not shown. A drop writes the target column's id to groupSource through an optimistic update: the card changes column at once, and a failed write puts the card back and notifies. A card drags only with edit access on the resource. The board imports from `/kanban` and installs dnd-kit. A card drags with mouse, touch or pen; a touch drag starts after a hold, so a swipe still scrolls the board. The `Move to` menu on each card is the keyboard path.
