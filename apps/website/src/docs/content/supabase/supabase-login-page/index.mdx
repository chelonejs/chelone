Chelone's `<LoginPage>` for the Supabase auth provider: an email and password form, a forgot password link and one OAuth button per provider in `providers`, none by default. `disableEmailPassword` hides the form, its divider and the link, and `disableForgotPassword` the link alone. `redirectTo` is forwarded to the form and to each button. Other props go to the `<div>` of `<LoginPage>`, and its static `path` is `/login`.

## Import

```tsx
import { SupabaseLoginPage } from "@chelone/react/supabase";
```

See the [Supabase pages guide](/docs/app-config/supabase-pages) for mounting the pages, the recovery flow, the provider buttons and the Vue slots.
