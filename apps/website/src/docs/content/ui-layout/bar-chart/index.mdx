One bar per row of a `data` array, `xField` along the axis and `yField` up it. The chart fetches nothing, so pass rows you already have, and a row whose `yField` is not a finite number is a gap: no bar is drawn for it. Each bar draws in the next theme chart color, cycled over the bars; pass `color` to draw every bar in one color. It is an add-on: import it from `@chelone/react/charts` or `@chelone/vue/charts`, and install `recharts` for React or `@unovis/vue` and `@unovis/ts` for Vue.
