A panel that lists the keys the current locale is missing, with an input per key and an export of the typed translations. The app creates a `createMissingKeyStore()`, passes `store.record` as `onMissingKey` to `createI18n`, and mounts the panel with that store. A key counts as missing even when it has a `_` fallback or the fallback locale holds it. The export is flat JSON to spread into a catalog.
