A line, or a filled area with `area`, over a `data` array: one point per row, `xField` along the axis and `yField` up it. The chart fetches nothing, so pass rows you already have, and a row whose `yField` is not a finite number is a gap in the line. It is an add-on: import it from `@chelone/react/charts` or `@chelone/vue/charts`, and install `recharts` for React or `@unovis/vue` and `@unovis/ts` for Vue.
