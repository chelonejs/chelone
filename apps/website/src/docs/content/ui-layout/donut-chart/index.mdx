One slice per row of a `data` array, `labelField` naming the slice and `valueField` sizing it. The chart fetches nothing, so pass rows you already have, and a row whose `valueField` is not a number above zero is a gap: it draws no slice. It is an add-on: import it from `@chelone/react/charts` or `@chelone/vue/charts`, and install `recharts` for React or `@unovis/vue` and `@unovis/ts` for Vue.
