A floating panel that lists the data provider calls a log recorded: method, resource, duration and the error of a failed call. Wrap the provider with `createDataProviderLog().wrap()`, pass the wrapped one to `<Admin>`, and mount the panel with the same log in development only, since it shows params and results.
